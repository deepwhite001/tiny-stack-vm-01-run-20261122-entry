A dependency-free interpreter for make.fun's tiny stack ISA: one run answers
all 40 programs of a set, writing each program's bytes and exit code. It
follows the ISA's hard rules: wrapping multiply, unsigned division and
comparison, five-bit shifts, signed remainder, every trap with its own code.
Practice: 1,000,000, 40/40.
